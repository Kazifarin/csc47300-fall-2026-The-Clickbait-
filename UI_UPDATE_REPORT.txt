CONSTRAINTS FOLLOWED
- No React or other frontend framework.
- No Tailwind, shadcn, Aceternity, Motion, Lucide, or other UI/animation libraries.
- No backend, database, API, authentication, or server-side application logic.
- All displayed resources remain bundled local sample data.
- Saved resources, reports, and theme choices stay in browser localStorage.
- TypeScript and esbuild are the only development dependencies; the production
  dependency tree is empty.

- The scene is an illustrative architectural model, not a navigable geographic map.
- Reports/bookmarks are local to the current browser and origin, not shared online.
- No new student-review system or backend workflow was added.
- No full WCAG certification, real-device/Safari audit or performance benchmark
  was claimed. Reduced-motion behavior is implemented in code/CSS; dedicated
  browser emulation of that preference was not part of the executed checks.
- Changes remain in the current branch's working tree; no commit, push or public
  deployment was performed for this UI update.
